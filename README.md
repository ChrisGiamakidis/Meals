# Meals Community

Meals Community is a full-stack Next.js application where users can browse meals, share recipes, join a food community, publish posts, and manage their own meal entries.

## Live Demo

https://mealcrafts.vercel.app/

## Features

- Browse paginated meals
- Search meals
- Share new recipes
- Edit and delete meals created by the logged-in user
- Hide default meals per account
- Restore hidden meals
- Upload meal images to Cloudflare R2
- Community authentication with signup, login, logout, and guest mode
- Create, edit, and delete community posts
- Demo users and seed data
- Server-side validation for meals, posts, authentication, and images
- CI workflow for linting, tests, and production build checks

## Tech Stack

- Next.js
- React
- Turso / libSQL
- Cloudflare R2
- JavaScript
- CSS Modules
- Vitest
- ESLint
- GitHub Actions
